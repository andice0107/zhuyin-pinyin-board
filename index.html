語音設定

建議語音（臺灣女聲）
  • Windows：用 Edge 開啟最好，選「HsiaoChen（自然）」或「HsiaoYu（自然）」。用 Chrome 選「Google 國語（臺灣）」。如果都沒有，到「設定 → 時間與語言 → 語音 → 新增語音」加入「中文（台灣）」。
  • iPad / Mac：選「美佳」。若沒有，到「設定 → 輔助使用 → 朗讀內容 → 聲音 → 中文（台灣）」下載「美佳（加強版）」音質更好。
  • Android：到「設定 → 系統 → 語言 → 文字轉語音」，引擎選 Google，語言選「中文（台灣）」並下載語音資料。

字音是用語音念「代表字」，例如 ㄅㄧㄥˇ 念「丙」。如果某個字音念起來怪，可以在主畫面按「換字」，或到〔錄音〕錄下正確的音。

錄音

按「● 錄」開始，唸完再按一次停止（最長 3 秒）。錄好會自動去掉前後空白並播放一次。有錄音的項目一律優先使用錄音。

聲符本音（必錄）

介音、韻符（選錄：語音念不準時再錄，橘色為建議錄音）

結合韻（選錄：點結合韻表時播放，橘色為建議錄音）

調名（選錄）

目前格子裡的字音（選錄）

讓所有裝置共用錄音

錄音只存在這台裝置的瀏覽器裡。要讓其他電腦、iPad、手機都能用：
  • 按「匯出語音包」下載 voice-pack.json，上傳到 GitHub 專案（和 index.html 放在同一層）。之後任何裝置打開網頁都會自動載入。
  • 或在另一台裝置按「匯入語音包」直接讀入這個檔案。
